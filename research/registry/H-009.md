# H-009: Month-End Proximity / High-Volatility Interaction on Reversion

## STATUS: REGISTERED, NOT YET ADJUDICATED

Per `research/registry/MECHANISM-MEMO-H009.md` (committed `a75e315`,

**This is Batch 2 / Phase 4's second registered hypothesis** (H-008 was

## 1. Mechanism reference

Full economic story, counterparty argument (informationless
rebalancing/fixing-adjacent flow), and prior are in the memo, not
repeated here. Summary: near-month-end flow produces a larger, more
visible, REVERTING price displacement specifically when it coincides
with an already-thin/high-volatility state, versus limited lasting
impact under normal depth conditions.

## 2. Prediction (falsifiable form)

**Primary/adjudicating cell:** near-month-end (`bars_to_month_end <= 1`,
`research/calendar_distance.py`) x top-ATR-tercile bars (H-005's frozen
edges, `H-005-bins.json`), pooled across all 5 instruments -- no
per-instrument asymmetry predicted (unlike H-008; this mechanism has no
instrument-class split). Reversion metric identical to H-008 Section
3c, k=3 primary / k=1 secondary-descriptive.

**Refutation clause 1 (interaction, not marginal) -- REQUIRES the
low/mid-tercile arm below to be interpretable, not just the primary:**
if reversion appears equally across all volatility regimes near
month-end, the interaction claim is refuted even if a marginal
calendar effect exists.

**Refutation clause 2 (persistence check):** if the near-month-end x
high-vol effect does NOT revert (continues in the same direction as
the triggering bar), that refutes the informationless-flow counterparty
story even if some effect exists.

**Quarter-end margin (non-adjudicating, pre-committed):** quarter-ends
(Mar/Jun/Sep/Dec) predicted to show a stronger effect than ordinary
month-ends. A reversed distinction is a disclosed embarrassment for the
mechanism, not silently dropped.

**Low/mid-tercile arm (non-adjudicating, added by memo amendment
`140ec71`):** near-month-end vs. ordinary, restricted to ATR terciles
1-2. Interpretation frozen: undercuts the interaction reading (does NOT
formally kill) if and only if its effect magnitude is >=50% of the
primary's, same sign. **Asymmetric: can only undercut a POSITIVE
primary result, cannot rescue a negative one.** Routed through the
identical `permutation_test`/`seed_dispersion` path as the primary via
`build_cell_calendar`, no lower-rigor treatment, but no FDR/BH slot.

## 3. Cells and FDR-by-cell accounting

**1 primary adjudicating cell** (pooled across instruments, not
per-instrument like H-008 -- this mechanism predicts no instrument
asymmetry, so pooling is the correct operationalization of the claim,
not an FDR-budget convenience). BH correction is therefore trivial
here (m=1) -- stated explicitly so it isn't mistaken for an omitted
step. The quarter-end margin and low/mid arm are both non-adjudicating
and outside the BH accounting entirely, per Section 2.

## 4. Kill criteria (any one refutes the primary)

- Primary cell fails sufficient-n (<30 either side), fails to exceed
  seed dispersion, or fails significance -> KILLED. The low/mid arm
  CANNOT rescue this outcome (Section 2's stated asymmetry).
- Primary cell effect does not revert at k=3 (continues same-signed)
  -> KILLED (refutation clause 2), regardless of significance.
- If the primary survives all of the above, the low/mid arm is then
  consulted: if it meets the >=50%-same-sign criterion, the survival is
  reported as UNDERCUT (interaction reading not supported, plain
  marginal effect cannot be ruled out) rather than a clean survival --
  this is a narrative qualifier on a survival, not a separate kill path.
