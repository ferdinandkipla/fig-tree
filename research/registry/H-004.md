**Consistency:** best session differs across all five (tokyo/london/
new_york all appear) -- fails the primary consistency criterion outright.
**Significance + noise check:** 2 of 5 instruments show p < 0.05
(USDJPY, GBPJPY), but **both fail the seed-dispersion check** -- their
observed effect is smaller than the noise generated purely by re-drawing
which random bars land in a session across seeds. 0 of 5 instruments
clear both bars simultaneously (need >=4/5 for the claim to survive).

**This is the same false-positive pattern H-002 caught at H4, now
confirmed at 1H.** Without the dispersion check, USDJPY and GBPJPY would
have been reported as "significant session effects" — exactly the trap
the check exists to catch, generalizing cleanly to a new granularity and
three additional instruments.

**Secondary (H4, EURUSD/AUDUSD, descriptive only, not adjudicated):**
no consistency, no effect exceeding noise either. Consistent with the
primary result; not counted toward the verdict per the registration.

### A real code bug found and fixed during this analysis
`np.random.Generator.shuffle()` on a pandas `StringArray` (produced by
`pd.concat` across 100 seed files) is not guaranteed correct — numpy
itself warns it "may contain duplicates after shuffling." This would
have silently corrupted every p-value in this analysis had it gone
unnoticed. Fixed by forcing a plain numpy object array before any
shuffle call; confirmed zero warnings post-fix by running with
`warnings.simplefilter('error')`.

## Prior evidence (recorded before test)
H-002 (killed, TRAIN, H4, 3 instruments) tested session structure
against the null model's random long entries and found no consistent
effect: best/worst session differed across all three instruments, p >
0.05 on two of three, and the one apparently-significant result
(GBPJPY) had an effect size smaller than seed-to-seed sampling noise.

H-002's own registration carried a standing, unresolved caveat: *"A
null result here means no session structure detectable at H4
granularity with this test, not that no session structure exists in
the market at any granularity. Sessions are defined in server time; a
single 4-hour bar can span meaningful overlap into an adjacent
session."* This hypothesis exists specifically to close that gap, now
that S1 has ingested 1H data for all five instruments (USDJPY, XAUUSD,
GBPJPY, EURUSD, AUDUSD) plus H4 for the two new instruments.

## The survivorship/pseudoreplication trap (inherited from H-002)
Unchanged from H-002: pooling seeds inflates apparent sample size
without inflating genuine independent evidence, because each seed
redraws WHICH bars are labeled entries from the SAME underlying,
autocorrelated price series. The seed-to-seed dispersion check (see
`research/registry/H-002.md`'s explicit template section) is mandatory
here too, not optional.

## Explicit note on NOT anchoring to trend_pullback
`trend_pullback` is retired (Phase 2 findings report, Section 4) --
none of its mechanisms survived testing. This hypothesis deliberately
does NOT match entry frequency to trend_pullback's specific signal
count (as M2/H-002 originally did), since doing so would silently
re-import the dead strategy's anatomy into a supposedly market-
structure-first test. Instead, entry frequency is set as a fixed,
round density (5% of eligible bars per instrument/timeframe) -- an
arbitrary but reasonable trading frequency, chosen purely for adequate
per-bin sample size, not derived from any prior strategy's logic.

## Prediction (the falsifiable form)
PRIMARY (1H, all 5 instruments): at least one session has a mean
expectancy on random long entries that is significantly different from
the others, in a DIRECTION consistent across all five instruments at
1H granularity.

SECONDARY, DESCRIPTIVE ONLY (H4, EURUSD/AUDUSD -- no claim, exploratory
extension of H-002's original 3-instrument H4 result to the 2 new
instruments): reported for completeness, not adjudicated against the
primary kill criteria.

## Test design
- Data: TRAIN window only (2019-01-01 -> 2022-01-01), per
  `research/S1_DATA_SPLIT.md` -- unchanged boundary, applies to all
  five instruments and both timeframes. OOS stays sealed.
- Null model: signed null (`strategies/null_random.py`, `signed=True`),
  100 seeds per instrument/timeframe combination, entry density fixed
  at 5% of eligible bars (not matched to any specific strategy's
  signal count -- see note above).
- Primary test set: 1H, all 5 instruments (USDJPY, XAUUSD, GBPJPY,
  EURUSD, AUDUSD).
- Secondary/descriptive set: H4, EURUSD and AUDUSD only (the two
  instruments H-002's original H4 test never covered).
- Per instrument/timeframe: pool all 100 seeds' TRAIN trades, compute
  per-session expectancy, run the same permutation test as H-002
  (2,000 shuffles, max|session_mean - pooled_mean| statistic), and
  compute the seed-to-seed dispersion check per session.
- The claim survives only if: the same session ranks best (or worst)
  in ALL FIVE primary (1H) instruments AND permutation p-value < 0.05
  in at least four of five AND the observed effect exceeds seed-to-
  seed dispersion in every instrument where p < 0.05 is claimed AND
  each claimed session has >= 30 pooled TRAIN trades in every
  instrument.

## Kill criteria (any one refutes the PRIMARY claim)
- Best/worst session inconsistent across the five 1H instruments.
- Permutation p-value >= 0.05 in two or more of the five 1H instruments.
- A "significant" permutation result (p < 0.05) whose effect size is
  smaller than that instrument's seed-to-seed dispersion -- same check
  that caught GBPJPY's false positive in H-002, applied here as a
  precondition for counting any p < 0.05 result as evidence, not an
  afterthought.
- Fewer than 30 pooled TRAIN trades in the claimed session for any of
  the five instruments -> INSUFFICIENT EVIDENCE for that instrument
  (does not by itself kill the others, but blocks a 5/5 consistent claim).
- Effect vanishes under cost +50% stress (deferred: only tested if the
  primary claim survives all of the above).

## What I will NOT do
- Match entry frequency to trend_pullback's signal count or any other
  dead strategy's logic -- see the explicit note above.
- Treat the H4 EURUSD/AUDUSD secondary results as adjudicated evidence
  for or against the primary claim; they are descriptive only.
- Report a p < 0.05 result without its accompanying seed-to-seed
  dispersion check, regardless of how clean the p-value looks.
- Select a session post-hoc after seeing which one "looks" different.
- Re-draw null model seeds -- uses the same seed range (0-99) as every
  prior signed/unsigned null sweep in this project.
- Unseal OOS.
