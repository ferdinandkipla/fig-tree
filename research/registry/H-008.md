## 1. Mechanism reference

Full economic story, counterparty argument, and prior (MEDIUM) are in
the memo, not repeated here. Summary: a high-ATR bar occurring during
an instrument's THIN (non-home) session is predicted to show more
subsequent partial reversion than the same volatility shock occurring
during a HOME/deep-liquidity session, because thin-session liquidity
cannot absorb the shock efficiently and correction arrives once
deep-session liquidity opens.

## 2. Prediction (the falsifiable form, per-instrument, per-condition)

Per the memo's Section 4, using `core/instruments.py`'s existing session
metadata (no new judgment call):

- **EURUSD, XAUUSD** (tokyo = thin session): high-ATR-tercile bars
  during `tokyo` show MORE subsequent partial reversion than
  high-ATR-tercile bars during `london`/`new_york`, on the SAME
  instrument.
- **USDJPY, GBPJPY, AUDUSD** (tokyo = home session): the tokyo-session
  high-volatility reversion effect is WEAKER OR ABSENT relative to
  EURUSD/XAUUSD's.

**Falsification condition, stated in advance:** if EURUSD/XAUUSD do not
show a distinguishably stronger tokyo-high-vol reversion effect than
USDJPY/GBPJPY/AUDUSD do, the mechanism as stated is REFUTED. A "no
group difference" result is a kill, not a reinterpretation opportunity
-- per the memo's own sign-specificity commitment.

## 3. Test-design parameters (frozen here, per charter requirement that these postdate the memo but predate any statistic)

### 3a. ATR tercile method: REUSE H-005's frozen edges

Per-instrument, TRAIN-window (2019-01-01 -> 2022-01-01), 1H terciles,
identical convention to H-005 -- **the SAME frozen edges from
`research/registry/H-005-bins.json`**, not re-derived. Reasoning
(recorded, not just asserted):

- Pooling across instruments is dimensionally incoherent (EURUSD ATR
  ~0.001 vs XAUUSD ATR ~3-5; pooled terciles would sort instruments,
  not volatility states).
- Reusing H-005's exact frozen bins introduces zero new researcher
  degrees of freedom and makes this test maximally comparable to the
  marginal test it conditions on: "H-005 found no marginal volatility
  effect; H-008 tests whether the same bins carry an effect
  conditional on session."
- The mechanism itself is per-instrument-relative ("high vol for THIS
  instrument's own distribution"), matching the memo's per-instrument
  sign prediction.

**Bin granularity, committed now:** this test uses the HIGH tercile
(T3) vs. the POOLED REMAINDER (T1+T2), not tercile-by-tercile
comparison. Stated explicitly per the charter's collapsing-bins caveat:
this is a top-tercile-vs-rest design, decided at registration, not
after seeing results. Rationale: the memo's mechanism is specifically
about a volatility SHOCK, not a graded volatility level -- "high vol"
is the operative condition, not a three-way ordinal comparison. Using
H-005's frozen T3 edge as the shock threshold, per instrument.

### 3b. Reversion window: 3 bars (1H) as PRIMARY/adjudicating; 1 bar as SECONDARY/non-adjudicating

- **Primary (adjudicating) statistic:** mean signed reversion measured
  3 bars after the high-ATR-tercile bar. Reasoning: the memo's causal
  story is "correction arrives once deep-session liquidity comes
  online" -- not an instantaneous next-bar effect. 3 hours (1H x 3) is
  long enough to span the thin-session tail into the following
  session's overlap, matching the memo's timescale, without being an
  arbitrary large window chosen after looking.
- **Secondary (non-adjudicating, descriptive only) statistic:** the
  same measurement at 1 bar. Registered now, reported alongside the
  primary result regardless of outcome, explicitly NOT used to decide
  the verdict. Purpose: if an effect appears at 1 bar but not 3 bars,
  that indicates a DIFFERENT (microstructure-speed) mechanism than the
  one committed in the memo, and the memo's mechanism is refuted as
  written even if some 1-bar effect exists -- this is recorded now so
  that outcome can't be quietly relabeled as a success later.
- **No window sweep.** One primary number, adjudicated once. A sweep
  over multiple windows, even FDR-corrected, is a soft form of the
  escape hatch the sign-specificity rule exists to close.

### 3c. Reversion metric, defined precisely

"Partial reversion" = for a high-ATR-tercile bar with signed return
`r0` (close-to-close, direction of the shock), the metric is
`-sign(r0) * (close[t+k] - close[t])` for k in {1, 3} -- i.e., positive
values indicate price moving back toward the pre-shock level; negative
values indicate continuation. Computed on RANDOM (null-model) entries
matched to `research/null_runs_h004/`'s existing 100-seed sweep, same
data-reuse pattern as H-005 (zero new simulation required -- this is
pure analysis on already-existing bar data plus session/ATR labels).

## 4. Cells and FDR-by-cell accounting

Per `research/CONDITIONAL_SEARCH_CHARTER.md`'s FDR-by-cell requirement:
this hypothesis defines **5 cells** (one per instrument: USDJPY,
XAUUSD, GBPJPY, EURUSD, AUDUSD), each comparing tokyo-high-vol-tercile
reversion vs. non-tokyo-high-vol-tercile reversion, on the SAME
instrument. This is a within-instrument comparison (5 cells), not a
session x tercile x instrument grid (which would be a much larger cell
count) -- the top-tercile-vs-rest collapse in 3a and the tokyo-vs-other
collapse both reduce the cell count deliberately, stated here so it
can't be revised upward or downward after seeing results.

**BLOCKING ISSUE, stated explicitly:** `research/fdr_check.py` currently

## 5. Kill criteria (any one refutes)

- EURUSD and XAUUSD do not both show a distinguishably stronger
  tokyo-high-vol reversion effect (at the 3-bar primary window) than
  USDJPY, GBPJPY, and AUDUSD do -- the core 2-vs-3 group prediction.
- The per-cell FDR-adjusted threshold (once the harness exists) is not
  cleared in both EURUSD and XAUUSD.
- A cell's effect that clears the per-cell threshold but is smaller
  than that cell's seed-to-seed dispersion (H-002/H-004/H-005's
  mandatory check, applied per cell here) -- required as a
  precondition, not an afterthought.
- Fewer than 30 pooled TRAIN trades in the tokyo-high-vol-tercile cell
  for any of the 5 instruments -> INSUFFICIENT EVIDENCE for that
  instrument, does not count as either a survival or a clean kill for
  that cell.
- Effect vanishes under cost +50% stress (deferred: only tested if the
  primary claim survives all of the above -- and even then, see §6).
